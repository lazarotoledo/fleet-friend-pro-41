# app-doec-frota

Quero criar um site para registrar as informações da frota de carro de empresa, onde vou ter que ter as equipes que o carro vai ficar, mas pode ocorrer de mudar, informações sobre o carro: placa cor modelo rastreado ou não, km inicial no momento da contratação, mensal  e contratada,  fazer o comparativo mensal do contrato com o atual, valor do contrato opcional, tempo de contrato atual e restante, condições, cobertura do seguro, uma aba manutenções: km para troca de oleo, troca de pneu, mecânica, avarias 
uma aba sinistro: com detalhamento, dia, relato, motorista, envolvidos.
